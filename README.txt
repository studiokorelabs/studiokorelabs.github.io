# Kore Labs — Redesign

Reworked as a more distinctive, premium agency site instead of a generic "tech agency" template.

## Included
- `index.html` — complete page
- `styles.css` — responsive visual system
- `app.js` — project previews, mobile menu, cursor interaction and form behavior

## Projects
Each project is now a single clickable card containing:
1. one visual preview image
2. project name
3. project category
4. arrow/link affordance

Edit the `projects` array in `app.js` to replace `href: "#"` with the real project URL.

The previews are embedded SVG images, so the page works without needing six extra image files.
